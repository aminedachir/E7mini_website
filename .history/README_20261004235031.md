# نظام إدارة العمليات والشكاوى — Police Platform

منصة Flask بنظامين في مشروع واحد:

1. بوابة المواطن لتقديم البلاغات والشكاوى **دون حساب** ومتابعتها برقم المرجع.
2. لوحة عمليات داخلية للشرطة لاستقبال وإدارة البلاغات والحوادث.

> **المرحلة الحالية: 3 — بوابة المواطن (تقديم/متابعة بلاغ بدون حساب).**
> المنجز: الأساس المعماري، الهوية البصرية RTL، بوابة المواطن، مصادقة الموظفين.
> غير منجز بعد: لوحة العمليات، API، الأدوار والصلاحيات.

## التقنيات

Python 3 · Flask (Application Factory + Blueprints) · Jinja2 · Flask-SQLAlchemy ·
Flask-Migrate · Flask-Login · Flask-WTF · Flask-Limiter · python-dotenv ·
SQLite (تطوير) · PostgreSQL (لاحقًا)
